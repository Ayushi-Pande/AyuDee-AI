## 🌟 About AyuDee AI

> **Technology should not replace human care — it should make care more connected, accessible, and meaningful.**

AyuDee AI brings **patients and caregivers into one connected digital ecosystem**.

Instead of focusing only on medical information, AyuDee focuses on everyday cognitive support — memories, routines, engagement, companionship and caregiver connection.

The platform provides two dedicated experiences:

👤 **Patient Space** — memories, routines, reminders, cognitive games and AI companionship.

🤝 **Caregiver Space** — connected support, memory management, activity insights and routine assistance.

---

# 🎯 The Problem

People experiencing memory or cognitive difficulties may struggle with everyday tasks such as:

- 🧠 Remembering meaningful people and moments
- ⏰ Following daily routines
- 💊 Keeping track of reminders
- 🧩 Staying mentally active
- 👨‍👩‍👧 Remaining connected with family and caregivers
- 😟 Finding simple support during moments of confusion

At the same time, caregivers often lack one simple digital space where they can support these everyday needs.

Most solutions treat these problems separately.

### 💡 AyuDee brings them together.

---

# 🚀 Our Solution

AyuDee AI creates a **personalized cognitive-care environment** built around four principles:

### 🧠 REMEMBER
Preserve meaningful memories and familiar moments.

### 🎮 ENGAGE
Encourage cognitive engagement through simple interactive activities.

### 🔗 CONNECT
Strengthen communication between patients and caregivers.

### 💙 SUPPORT
Provide routines, reminders, accessibility tools and gentle AI assistance.

# ✨ Core Features

## 🧠 Memory Vault

A personal digital memory space where meaningful moments can be preserved and revisited.

**Capabilities:**

- 📸 Store important memories
- 👨‍👩‍👧 Preserve family moments
- 📝 Add descriptions and context
- ❤️ Revisit familiar experiences
- 🤝 Caregiver-supported memory management

---

## 🎮 Brain Studio

Interactive cognitive activities designed to make mental engagement simple and enjoyable.

**Includes:**

- 🃏 Memory matching activities
- 🧠 Cognitive exercises
- 🎯 Simple challenges
- 🔥 Activity streak tracking
- 📊 Engagement progress

The goal is not medical diagnosis or treatment — it is **accessible cognitive engagement**.

---

## 📅 Today's Journey

A clear daily timeline helps users understand what comes next.

Example routine:

```text
08:00 AM  → Morning Reminder
10:30 AM  → Appointment
12:15 PM  → Lunch
03:00 PM  → Cognitive Activity
```

Users can mark activities as completed and track daily progress.

---

## ⏰ Smart Reminders

Create and manage reminders for important everyday activities.

Designed to be:

✔ Clear  
✔ Simple  
✔ Accessible  
✔ Easy to manage

---

## 🤖 Ayu Companion

A gentle AI-inspired companion experience designed to provide a familiar place to:

- 💬 Talk
- 🧠 Remember
- 📅 Plan
- 💙 Receive supportive guidance

Ayu Companion is designed as a **support feature and not as a replacement for professional medical care**.

---

## 🤝 Caregiver Connection

A dedicated caregiver experience allows family members or caregivers to stay connected with the user's daily journey.

Caregiver features include:

- 📊 Routine overview

- 📈 Activity insights
- ⏰ Reminder management
- 👨‍👩‍👧 Connected care experience

## 🆘 Help & Safety

A dedicated support area provides quick access to:

☎️ Caregiver contact  
🚨 Emergency information  
🧘 Grounding guidance  
💙 Simple reassurance steps

AyuDee is intentionally designed as a **non-diagnostic cognitive support platform**.

# ♿ Accessibility First

Cognitive-care technology must be easy to use.

AyuDee therefore includes accessibility controls such as:

| Feature | Purpose |
|---|---|
| 🔠 Large Text | Improved readability |
| 👁️ Easy View | Simplified visual experience |
| ⚡ High Contrast | Better visibility |
| 🌿 Reduced Motion | Comfortable navigation |

Our goal is to make technology adapt to the user — **not force the user to adapt to technology.**

# 💻 Run Locally

### 1️⃣ Clone the repository

```bash
git clone https://github.com/Ayushi-Pande/AyuDee-AI.git
```

### 2️⃣ Open the project

```bash
cd AyuDee-AI
```

### 3️⃣ Start Frontend

```bash
cd frontend
npm install
npm run dev
```

Open the local URL displayed by Vite.

### 4️⃣ Backend

Open another terminal:

```bash
cd backend
```

Install the backend dependencies according to the backend configuration and start the FastAPI server.
